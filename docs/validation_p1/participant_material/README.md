## 1. TUJUAN & SPESIFIKASI MATERI

Direktori ini memuat seluruh materi peraga visual yang **diizinkan untuk ditampilkan langsung ke hadapan validator** selama pelaksanaan **Tahap 1 (Blind Observation)**.

### Prinsip Nol Kebocoran Informasi (*Zero Information Leakage*):
1. **Nama File Sumber Dihilangkan**: Tidak ada jejak nama file seperti `A _Hitam_Iphone_14Pro.jpg` atau `20240509_...`.
2. **Label Kelas Dihilangkan**: Tidak ada huruf A, B, C, D atau abjad apa pun pada materi.
3. **Struktur Folder Dihilangkan**: Tidak ada path `/A/` atau `/B/`.
4. **Deskripsi Peneliti Dihilangkan**: Tidak ada teks morfologi (seperti "dua tangan segitiga" atau "telapak terbuka").
5. **Instruksi Seragam & Netral**: Seluruh kartu menggunakan kalimat petunjuk yang identik:
   > *"Petunjuk: Perhatikan konfigurasi tangan pada gambar di atas secara seksama. Silakan sampaikan apa yang Anda amati berdasarkan pengalaman komunikasi isyarat Anda."*
